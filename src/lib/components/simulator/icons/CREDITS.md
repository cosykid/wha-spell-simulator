# Icon credits

The arcane canvas-chrome glyphs in this folder (`Arcane*.svelte`) are derived
from [game-icons.net](https://game-icons.net), by **Delapouite**, licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

| Component               | Original icon          |
| ----------------------- | ---------------------- |
| `ArcaneMenu.svelte`     | spell-book             |
| `ArcaneUndo.svelte`     | anticlockwise-rotation |
| `ArcaneRedo.svelte`     | clockwise-rotation     |
| `ArcaneBroom.svelte`    | magic-broom            |
| `ArcaneRecenter.svelte` | crosshair              |

`ArcaneZoomIn.svelte` and `ArcaneZoomOut.svelte` are authored in-house (a filled
magnifying glass with a plus/minus), since game-icons has no plus/minus lens.
